# OmnisecAI - AI Security Platform

Enterprise-grade security for AI models, LLMs, and cloud infrastructure.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Technology Stack

- React 19
- Next.js 15
- Material UI v7
- TypeScript
